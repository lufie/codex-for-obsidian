正文：

我做了一个 Obsidian 插件：Codex for Obsidian。

它可以把本地 OpenAI Codex CLI 接进 Obsidian 侧边栏里，在笔记知识库中直接使用 GPT/Codex。

我最想解决的是这个问题：

写作、整理资料、维护代码笔记时，我不想一直在 Obsidian、终端、浏览器之间来回切。最好 AI 就在知识库旁边，能读上下文，也能帮我改笔记、分析文件、执行本地 Codex 能力。

现在这个插件支持：

- Obsidian 侧边栏内直接和 Codex 对话
- GPT-5.5 模型选择
- 确认模式 / 全自动 / 计划模式
- 笔记上下文、图片、文件附件
- 复用本地 Codex 的 skills、MCP、subagents
- 中英文等多语言界面

这个项目是基于 Claudian 自己 vibe coding 出来的 Codex-first 版本。Claudian 原本做 Claude Code + Obsidian，我把它改造成了面向 OpenAI Codex 的插件，并且把设置页、模型选择、权限模式、多语言和 README 都重新整理了一遍。

适合这些人：

- 深度使用 Obsidian
- 已经在用 Codex CLI
- 想把 AI 工作流放进自己的知识库
- 喜欢本地优先、可控、可扩展的工具
